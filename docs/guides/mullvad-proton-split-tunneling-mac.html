Split tunneling on Mac with Mullvad, Proton, IVPN or your own server

If your provider gives you a WireGuard config, you can route individual Mac apps through it. Here's the short version for each.

Mullvad

Mullvad's own app has split tunneling built in on macOS, and it's included with your subscription. If Mullvad is the only VPN you use, start there — no reason to pay for anything else.

Where a separate tool helps is if you also use another provider, or want the opt-in model (your Mac stays on its normal connection, apps join the tunnel) rather than excluding apps from a full tunnel. For that, download a WireGuard config from your Mullvad account and import it.

ProtonVPN

Proton has no split tunneling on macOS. Their WireGuard configs are at account.protonvpn.com → Downloads → WireGuard configuration: pick a server, generate, download the .conf.

IVPN and AirVPN

Both publish WireGuard configs from your account area. AirVPN's include a preshared key, which is handled fine.

Your own WireGuard server

A VPS with WireGuard costs a few dollars a month and gives you an exit IP nobody else shares. Use the client config you generated when you set the server up.

Importing a config

In VPNonly: click the provider name at the bottom of the window, choose Import WireGuard config…, and pick the .conf file. One file per server; import as many as you like and switch between them from the same menu. Then flip the switch next to any app.

With the free command-line version instead:

sudo ENDPOINT=1.2.3.4:51820 PEER_KEY=<server public key> CLIENT_IP=10.64.0.2 ./up.sh
sudo ./run.sh /Applications/YourApp.app

Two details worth knowing

Providers hand out wg-quick configs, which include Address, DNS and sometimes MTU lines. Plain wg setconf rejects those, so anything importing them has to strip them and apply the address separately — if you're scripting this yourself, that's the part that will bite you first.

Second: an IPv6-only config won't work with a tool that routes IPv4. Most provider configs include both, so this rarely comes up, but it's worth knowing if a config is refused.
