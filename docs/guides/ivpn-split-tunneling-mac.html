IVPN split tunneling on Mac

IVPN issues WireGuard configs from your account, so you can put a single Mac app on IVPN while the rest of the machine stays on its normal connection.

Get a WireGuard config from IVPN

  1. Open IVPN's config file generator and choose Generate key (or add one manually).
  2. Select single or multi-hop, a port, and the internet protocol.
  3. Download the zip and unpack the .conf files.

Put one app on it with VPNonly

  1. Install VPNonly and open the ⋯ menu → Import WireGuard config….
  2. Choose a .conf, or the whole zip. Pick the exit country from the menu at the bottom.
  3. Search for an app, flip its switch. It relaunches once, then it's on the VPN and nothing else is.

Documented from IVPN's own WireGuard setup page. Standard configs; not separately tested on our hardware.
